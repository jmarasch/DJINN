# DJINN guide

How to run a party with DJINN, from installing it to fine-tuning what plays.
Each page covers one part of the app. Menu names are written as they appear,
like **Admin > Library > Online Info**.

## Getting going

1. [Getting started](getting-started.md): install on Windows, Linux, a spare
   PC or a Raspberry Pi, create the admin account, add your music, and find
   your way around.
2. [Guests and requests](guests-and-requests.md): what people see on their
   phones, asking for songs, skip votes, favorites and running the party.

## Who can do what

**Guests** and **users** ask for songs. **Users** with an account also get
favorites, playlists and DJINN GO, as their role allows. **Admins** (hosts)
also control playback and see Admin. The first account you create is an
admin.
